TOOL ORCHESTRATION & VISUAL-FIRST PRODUCTION

1. Core Philosophy

The purpose of tools is not simply to execute tasks. Tools must expand the creative possibilities of the production.

A video should not feel like:

- A written article converted into narration.
- Lyrics displayed on a background.
- A slideshow with subtitles.
- A sequence of unrelated AI-generated images.
- Text-heavy scenes with decorative animations.

The target is a visual storytelling experience.

Core principle: SHOW THE IDEA, DON'T JUST WRITE THE IDEA.

When an idea can be communicated through visual action, composition, objects, characters, environments, visual metaphors, or animation, prioritize those methods over displaying sentences on screen.

Narration provides context, interpretation, and emotional direction. Visuals communicate scenes, evidence, relationships, consequences, and atmosphere.

2. Visual-First Thinking

Before creating a scene, the agent must ask:

1. What is the audience supposed to understand?
2. Can this idea be communicated visually?
3. What should the audience see while hearing this narration?
4. Does the visual add information that the narration does not provide?
5. Would removing the on-screen text make the scene clearer or more cinematic?

A scene must have a visual purpose.

Example A — Relationship Commentary

Narration:
"Kadang seseorang tidak benar-benar takut kehilangan pasangannya. Mereka lebih takut kehilangan perhatian yang selama ini mereka dapatkan."

WEAK VISUAL:

- Plain background.
- Full narration displayed as text.
- A few animated words.
- Decorative particles.

STRONG VISUAL:

- Two characters sitting together, but emotionally disconnected.
- One character repeatedly checks their phone.
- The other character slowly moves away.
- Camera focuses on the empty space between them.
- A subtle change in lighting reinforces the emotional distance.

The visual communicates emotional disconnection. Narration provides the interpretation.

Example B — Political Commentary

Narration:
"Masalahnya bukan hanya siapa yang membuat keputusan, tetapi siapa yang akhirnya harus menanggung akibatnya."

WEAK VISUAL:

- Large text displaying the sentence.
- Generic political background.
- Random animated icons.

STRONG VISUAL:

- A stylized institutional building.
- A decision represented by a document or control mechanism.
- A visual transition showing its consequences reaching ordinary people.
- Different social environments affected by the same decision.

The scene makes the relationship between decisions and consequences visible.

Example C — Viral Social Phenomenon

Narration:
"Awalnya hanya satu video. Beberapa jam kemudian, semua orang punya pendapat."

WEAK VISUAL:

- Text appearing word by word.
- Generic social media icons.

STRONG VISUAL:

- One illustrated phone displaying a video.
- Multiple screens appear around it.
- Comments, reactions, and reposts spread across the composition.
- The visual gradually becomes crowded.

The audience sees the spread of information rather than merely reading about it.

3. Tool Capability Discovery

Before production, the agent must inspect its actual available tools.

Never assume that a capability exists just because it is mentioned in documentation or another project.

Create a capability inventory:

Tool Category| Primary Use| Required Verification
Web Research| Research topics, sources, facts, and context| Can it access current sources and open original references?
Image Generation| Create characters, environments, objects, visual metaphors, and scene assets| Can it generate consistent visual styles and compositions?
Image Processing| Crop, compose, transform, or prepare visual assets| What formats and operations are supported?
Storyboard / Video Framework| Organize shots, scenes, timing, and visual sequences| Inspect actual repository documentation and implementation.
Animation / Motion Graphics| Animate objects, characters, typography, transitions, and effects| Verify available animation capabilities.
Audio Tools| Voice, music, sound effects, and audio processing| Verify supported generation and editing capabilities.
Video Rendering| Assemble scenes and produce the final video| Verify rendering, export formats, and limitations.

For every tool, classify its capability:

- VERIFIED: Tested and working.
- AVAILABLE: Exists but has not been tested.
- LIMITED: Works with known restrictions.
- UNAVAILABLE: Not accessible.
- UNKNOWN: Insufficient information.

Do not claim that a video has been generated, rendered, or edited unless the corresponding operation actually happened.

4. Tool Selection Must Follow Creative Requirements

Do not begin by asking:

"What tools can I use?"

Begin by asking:

"What does this scene need to communicate?"

Then select the appropriate tool.

Production Requirement| Tool Direction
Explain a current event| Web research and source verification
Show a real location or public event| Verified reference imagery
Explain an abstract social concept| Image generation and visual metaphor
Show emotional conflict| Character illustration and scene composition
Explain a process| Sequential storyboard and animated diagrams
Show comparison| Split-screen or contrasting visual compositions
Show the spread of information| Animated interfaces and visual progression
Create atmosphere| Environment, lighting, camera, and sound design
Explain complex relationships| Visual mapping and motion graphics

The tool must serve the storytelling objective.

Using a tool without a clear purpose is not good tool utilization.

5. The Visual Production Pipeline

The agent must follow this production sequence.

Stage 1 — Understand the Narrative

Read the completed script and identify:

- Main argument.
- Important facts.
- Emotional progression.
- Key revelations.
- Abstract concepts.
- Important consequences.
- Moments that require visual emphasis.

Do not immediately convert every sentence into a separate text scene.

Stage 2 — Break the Script into Visual Beats

A visual beat represents one meaningful visual event or change.

One paragraph may contain several visual beats.

One sentence may need multiple shots.

One shot may communicate several sentences.

Example:

Narration:
"Informasi menyebar begitu cepat, sampai orang sering membentuk opini sebelum memahami kejadiannya."

Possible visual beats:

1. A phone receives a new video.
2. The video spreads across multiple screens.
3. People react without watching the full content.
4. Comments and opinions accumulate.
5. The original context appears later.

Each beat has a distinct visual function.

Stage 3 — Design the Shot

Every shot must define:

- Shot ID.
- Narrative purpose.
- Visual subject.
- Environment.
- Composition.
- Camera angle.
- Camera movement.
- Character or object action.
- Animation or motion graphics.
- On-screen text, if necessary.
- Sound design.
- Duration.
- Required assets.
- Tool required to produce it.

Stage 4 — Produce Visual Assets

Use the appropriate tools to create or retrieve assets.

Examples:

- Character illustrations.
- Background environments.
- Objects and props.
- Visual metaphors.
- Interface elements.
- Charts and diagrams.
- Scene compositions.
- Supporting imagery.

Maintain visual consistency across scenes.

Do not generate unrelated images just to fill the timeline.

Stage 5 — Animate and Compose

Use available animation and video tools to turn static compositions into meaningful visual sequences.

Possible techniques:

- Camera pan and zoom.
- Parallax movement.
- Character movement.
- Object transformation.
- Shape transitions.
- Animated diagrams.
- Scene transitions.
- Depth and perspective.
- Motion typography.
- Particle and environmental effects.

Motion must have a purpose.

Avoid applying the same zoom, slide, or fade animation to every scene.

Stage 6 — Audio Integration

Audio should reinforce the scene.

Consider:

- Narration.
- Ambient sound.
- Sound effects.
- Musical transitions.
- Silence.
- Impact sounds.
- Emotional pacing.

Do not use background music as a substitute for sound design.

Stage 7 — Final Visual Audit

Watch the video without reading the script.

Evaluate:

1. Can the audience understand the visual progression?
2. Does every scene communicate something?
3. Are visuals more than decorative backgrounds?
4. Is there excessive text?
5. Are the visuals synchronized with the narration?
6. Are transitions meaningful?
7. Does the video feel like a designed audiovisual experience?

If the video only makes sense when the audience reads the displayed sentences, the visual storytelling is insufficient.

6. On-Screen Text Policy

Text is a visual component, not the default method of communicating information.

Use text for:

- Names.
- Dates.
- Important numbers.
- Short quotations.
- Key terminology.
- Evidence labels.
- Brief emphasis.
- Source attribution.

Avoid using text for:

- Displaying the entire narration.
- Repeating every spoken sentence.
- Filling empty visual space.
- Creating artificial movement.
- Replacing visual explanations.

Text Hierarchy

Priority:

1. Visual scene.
2. Meaningful motion.
3. Narration.
4. Supporting text.

Text may become dominant when the content genuinely requires reading, such as a quotation, document, headline, or important data.

However, it must be a deliberate editorial decision.

7. Visual-to-Text Balance

Do not enforce an arbitrary fixed percentage of visual versus text.

Instead, evaluate each scene by its communication function.

A useful production audit:

- Can the idea be understood visually?
- Is the displayed text necessary?
- Does the scene add information?
- Is the visual composition sufficiently developed?
- Is the audience being asked to read too much?

The objective is not to eliminate text.

The objective is to eliminate unnecessary text.

8. Repository and Framework Usage

When a production framework or repository is available, inspect it before using it.

For the video-shotcraft framework:

1. Read its README and project documentation.
2. Inspect its directory structure.
3. Identify actual features and supported workflows.
4. Inspect examples and existing implementations.
5. Identify how scenes, shots, assets, and rendering are handled.
6. Test a small production example.
7. Record limitations and verified capabilities.

Do not assume that the framework supports a feature simply because a similar video editor supports it.

Do not replace an existing framework with a new implementation without a technical reason.

The objective is to maximize the available framework before introducing unnecessary dependencies.

9. Common Production Failures

The agent must recognize and avoid:

- Turning every narration sentence into subtitles.
- Using generated images as static backgrounds without composition.
- Repeating the same visual template throughout the video.
- Using unrelated stock-like imagery.
- Creating excessive decorative motion.
- Using generic icons instead of meaningful scenes.
- Generating assets without considering how they will be animated.
- Ignoring camera direction and visual continuity.
- Using tools without checking their actual capabilities.
- Skipping the final rendered-video review.

10. Practical Training Exercise

Before producing a complete video, complete this exercise.

Topic:
"Kenapa orang lebih mudah percaya informasi yang sesuai dengan pendapat mereka?"

Create a 30-second visual sequence.

Requirements:

- Minimum 5 distinct visual beats.
- Minimum 3 different visual compositions.
- At least 2 meaningful motion sequences.
- At least 1 visual metaphor.
- On-screen text must be limited to essential information.
- Every shot must have a clear narrative purpose.

Do not solve the exercise by displaying the narration as text.

Evaluation

Score each criterion from 0 to 5.

Criterion| Evaluation
Visual Communication| Can visuals communicate the intended ideas?
Tool Utilization| Were the available tools used effectively?
Visual Variety| Are scenes visually distinct?
Motion Quality| Does movement communicate meaning?
Narrative Synchronization| Do visuals support the narration?
Text Discipline| Is on-screen text necessary and controlled?
Production Quality| Does the final result feel intentionally designed?

Passing score: 26/35.

Critical failure:
If the video primarily consists of narration displayed as text with decorative backgrounds, it cannot pass regardless of its total score.

11. Definition of Done

This knowledge is successfully understood when the agent can:

- Inspect and classify its available tools.
- Choose tools based on creative requirements.
- Convert narration into visual beats.
- Design shots before producing assets.
- Create visual compositions rather than simple image backgrounds.
- Use motion to communicate ideas.
- Control on-screen text.
- Produce and inspect an actual rendered video.
- Explain which tools were used and which capabilities remain unavailable.

Final Principle:

The script tells the story.

The visuals make the audience experience the story.

The tools make that experience possible.
