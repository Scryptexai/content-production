# Storytelling Agent Knowledge Pack

A modular Indonesian-first storywriting system for Codex, Claude Code, Node.js agents and other file-aware AI agents.

## Quick start
Place this directory in your agent workspace. Instruct your agent: "Read AGENTS.md, then create an original Indonesian story following WORKFLOW.md. Use the relevant SKILL.md files, maintain the story bible, and finish with the editorial audit."

## Contents
- `AGENTS.md`: top-level instructions and routing
- `knowledge/`: narrative theory, output schema, continuity template
- `skills/`: eight task-specific skill directories
- `WORKFLOW.md`: orchestration and handoff schema

## Customization
Set format, genre, audience, target duration, voice and production limits in the user brief. This pack supports horror, comedy and other narrative genres; adapt the genre module when necessary.

## Caution
Rubric scores are editorial judgments, not calibrated predictors of views or retention. Evaluate against actual audience data when available.
