# 03_SOCIAL — profile, headers, post templates

Generated by `tools/build_channel.py`. Sizes are the 2026 platform specs for the three surfaces
ODDCHAPTER uses; anything else re-crops from the 1080 square.

| File | Size | Use |
|---|---|---|
| `profile/SOCIAL_PROFILE_1024` | 1024 × 1024 | profile picture on every platform |
| `profile/SOCIAL_HEADER_DARK` | 1500 × 500 | X / YouTube / Facebook header, dark |
| `profile/SOCIAL_HEADER_LIGHT` | 1500 × 500 | header for light contexts, print, deck title |
| `post_templates/SOCIAL_POST_1080` | 1080 × 1080 | square post / carousel base |

## Crop safety

Platforms crop to a centred circle (avatars) or a wide band (headers). The mark is placed inside
the **central 60 %** of the square and the header lockup inside the central 70 % of the 1500 × 500,
so a circular crop or a mobile band never clips the monogram.

## Post template

`SOCIAL_POST_1080.svg` follows the same convention as the thumbnails: a clipped group with
`id="image-slot"` (diagonal hatch + `FOTO · SLOT GAMBAR`) that you replace with the episode still.
Headline and episode label stay live text so the copy can change per post without redrawing.

Rule of one: **one** orange element per post — the episode number chip, or one word, never both.

## What is not here

Stories/reels (1080 × 1920) and link-preview cards are not produced. If they are needed, they
should be derived from the 1080 square rather than improvised, so the safe areas stay consistent.
