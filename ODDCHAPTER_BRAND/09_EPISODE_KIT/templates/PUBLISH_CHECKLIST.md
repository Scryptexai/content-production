# Publish checklist — <EPISODE TITLE>

Copy into `05_PUBLISH/` and tick it. If a box is unticked, it does not ship.

## Asset

- [ ] Thumbnail 1280×720 from a template (`02_YOUTUBE/thumbnails/`), ≤ 4 words, one orange element
- [ ] End card in the last 20 s (`02_YOUTUBE/end_card/`)
- [ ] Vertical cut / short, if the story allows it (`03_SOCIAL/stories/`)

## Master

- [ ] 1920×1080 · 25 fps · H.264 high profile · 16–20 Mbps
- [ ] Audio −14 LUFS integrated, −1.0 dBTP true peak
- [ ] Subtitles burned or uploaded; Inter 500 42 px, max 2 lines, 90 % ink plate
- [ ] No text outside the 120 px safe margin
- [ ] Signature read once; no second logo animation

## Metadata

- [ ] Title ≤ 60 characters, no question the film does not answer
- [ ] Description: 2-line hook · what is in the film · sources · chapters
- [ ] Chapters start at `00:00`, minimum 3, each ≥ 10 s
- [ ] Tags: 8–12, no repetition of the title verbatim
- [ ] Credit list for every photo, document and archive used

## Channel

- [ ] End screen: next episode + subscribe element
- [ ] Cards at the two moments the audience might leave
- [ ] Playlist assigned
- [ ] Community post scheduled (one frame + one sentence)
- [ ] Pinned comment: a question about the story, not about subscribing

## After

- [ ] Watch the first 48 hours on a phone, at arm's length, sound off — does the thumbnail survive?
- [ ] Write down what the retention graph says in `06_NOTES/`
